Quadra 605 PGA 68040 to QFP 68040 Adapter

Simple adapter to use a QFP CPU in a Quadra 605. NOTE: Orientation sensitive, please check if it will work in your machine.
Optional fan header and a jumper that can be cut to feed 3.3v instead (for use with a V suffix CPU). Will work with FPU-less CPUs also.
